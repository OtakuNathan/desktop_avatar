# Pal 表情小样

启动桌宠后访问 `/previews/pal-blink/index.html`，或用静态 HTTP 服务打开本目录。
这是无 WebSocket、无 Pal 工具调用的独立美术预览。正式桌宠已采用这一形象；两者共用 `client/js/pal-raster-animation.js` 和 `pal-raster-art.js`，运行时纹理位于 `client/assets/model/pal-raster/`。

`face-base.png` 是依据 Pal 原稿生成的自然垂手、空白脸屏底图。
SVG 绘制眼睛、眉毛、嘴和脸颊；眨眼围绕眼睛中心收束，保留虹膜比例。
`sheet.png` / `clean-sheet.png` 保留前一版眨眼与眼部清理小样。

沿用桌宠语义：`standby`、`thinking`、`working`、`sleeping` 为基础状态，
好奇星星眼、喜欢爱心眼、wink、开心、惊醒等临时表情结束后回到基础状态。
`snacking` 演示悬浮能量芯片进食与咀嚼；它是美术动作，没有充电或系统资源含义。
“模拟收到消息”演示 sleeping → shock → thinking。真正的超时睡眠循环由服务端负责。

暂停、页面不可见时停止动画计时；减少动态效果偏好默认暂停，仍可手动选择静态表情。
思考时先抬眼，随后头顶短暂亮起灯泡；星星眼与爱心眼轻轻缩放，星星眼带闪烁粒子。
wink 先闭合成 `<` 再睁开；生气显示漫画怒气，睡觉时 Zzz 在头顶向上飘散。
进食不显示咀嚼文案，结束时头顶浮出 `ENERGY +1`。
默认只显示上半身，通过“显示全身”切换；裁切由容器完成，完整底图保持不变。

`body-plate.png` 是移除手臂的单格底板（592×887），去掉了未使用的后两格。
手臂在 SVG 中从 `arm-texture.png`（263×225）裁切显示，保留原图坐标映射，肩、肘、腕构成嵌套关节；
`greeting` 挥手，`thinking` / `confused` 先弯肘再抬手到头侧；挠头阶段固定肩、腕，仅前臂小幅屈伸，随后先落肩再伸肘收回。
思考期间瞳孔向上左右移动；鼠标跟随只在 standby 且未眨眼时生效，避免覆盖动作眼神。
头顶 ENERGY 与 Zzz 字号已增大；疑惑挠头时显示轻晃的 `???`。
`hand-poses.png` 降采样至 768×512，仍映射至原 1536×1024 SVG 坐标，提供专用挥手、背手挠头和捏取姿势，使用 SVG 轮廓裁切显示。
图集是 RGB（生成的棋盘格并非透明通道），不应当作透明 PNG 直接贴图使用。
进食手型按右手朝向镜像，裁掉素材多余腕口并将掌根连接到腕关节。
芯片位置由手型图层的完整矩阵变换得到，跟随捏取点送到嘴边后消失，随后收手咀嚼。
工作等其他手部动作尚未制作。
正式版以 SVG 轮廓裁切底图背景，并已接入 renderer 完成事件。

实际加载的三张纹理合计 1,284,109 字节，优化前为 5,603,023 字节，减少约 77%。原始清晰素材在本地缓存留档，旧小样不参与页面加载。
